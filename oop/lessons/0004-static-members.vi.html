Static member: state dùng chung và hằng số

OOP (Lập trình hướng đối tượng) · Bài 0004 · bước 4/22 · Foundation · ~10 phút · Trang chủ · Lộ trình OOP · Lộ trình tổng · English

Thành quả hôm nay: nói được static field và static method là gì, và vì sao static method không dùng được this.

Class variable

"Các field có modifier static trong khai báo được gọi là static field hay class variable. Chúng gắn với class, chứ không gắn với object nào cả. Mọi instance của class đều dùng chung một class variable, nằm ở một vị trí cố định trong bộ nhớ."[1]

Class method

"Class method không thể truy cập trực tiếp instance variable hay instance method; chúng phải dùng một object reference. Ngoài ra, class method không dùng được từ khoá this vì không có instance nào để this trỏ tới."[1] Hằng số kết hợp static và final, theo quy ước đặt tên VIẾT_HOA.[1]

java oop/examples/StaticMembers.java
before: 0
after 3 objects, shared count = 3
instance ids: 1, 2, 3
constant: 100

Một bộ đếm dùng chung, nhưng mỗi object có id riêng. Mã nguồn: StaticMembers.java. Cảnh báo về thiết kế: state static có thể thay đổi chính là state toàn cục (global state), khiến code khó test (xem bài Singleton).

Luyện truy hồi

Trả lời theo trí nhớ. Mỗi câu chỉ một lần chọn.

1. Một static field có bao nhiêu bản sao?

Mọi instance dùng chung class variable.[1]

2. Static method có dùng được this không?

Không có instance nào để this trỏ tới.[1]

3. Hằng số được khai báo bằng...?

static final dùng để định nghĩa hằng số.[1]

4. Bộ đếm static sau khi tạo 3 object?

Demo in ra shared count bằng 3.
