Abstract class

Một abstract class "không thể được khởi tạo (instantiate)" nhưng có thể được kế thừa, và có thể chứa cả method abstract lẫn method không abstract. Một class có method abstract thì bản thân nó phải là abstract; subclass thường sẽ hiện thực các method đó, nếu không thì nó cũng phải là abstract.[1]

Khi nào dùng cái nào (hướng dẫn của tutorial)

  • Abstract class: chia sẻ code giữa các class có quan hệ gần gũi; cần member không public hoặc field non-static, non-final.
  • Interface: các class không liên quan gì với nhau sẽ implement nó; muốn đặc tả behavior mà không áp đặt cách hiện thực; muốn đa kế thừa về kiểu (multiple inheritance of type).[1]

Luyện truy hồi

Trả lời theo trí nhớ. Mỗi câu chỉ một lần chọn.

1. Có thể khởi tạo một abstract class không?

Abstract class không thể được khởi tạo.[1]

2. Một class có thể extend bao nhiêu class?

Chỉ một, nhưng có thể implement nhiều interface.[1]

3. Cần field state dùng chung. Chọn gì?

Interface chỉ cho phép field public static final.[1]

4. Các class không liên quan cần chung một năng lực. Chọn gì?

Dùng interface khi các class không liên quan cùng implement nó.[1]
