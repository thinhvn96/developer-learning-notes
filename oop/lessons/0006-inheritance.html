Inheritance: extends, super and is-a

OOP (Object-Oriented Programming) · Lesson 0006 · step 5 of 22 · Core · ~10 minutes · Home · OOP (Object-Oriented Programming) ladder · Roadmap · Tiếng Việt

Today's win: use extends and super, explain constructor chaining, and say what 'is-a' promises.

Idea

Classes can inherit commonly used state and behavior from other classes: the superclass is the parent; subclasses inherit. In Java "each class is allowed to have one direct superclass, and each superclass has the potential for an unlimited number of subclasses." Syntax: class MountainBike extends Bicycle, which gives it all of Bicycle's fields and methods while its own code focuses on what is unique.[1]

java oop/examples/InheritanceDemo.java
Bike constructor
MountainBike constructor
gear 6, speed 12, full suspension
b instanceof MountainBike: true
Bike constructor
new Bike() instanceof MountainBike: false

The subclass constructor calls super(gear) first, so the parent part is built before the child part; super.describe() reuses the parent's behavior inside an override; instanceof shows the is-a relationship in one direction only. Source: InheritanceDemo.java.

Inheritance couples the subclass to its parent's implementation. The composition lesson shows a real bug this causes; use inheritance for genuine is-a relationships and stable base classes.
