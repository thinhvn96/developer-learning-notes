Static members: shared state and constants

OOP (Object-Oriented Programming) · Lesson 0004 · step 4 of 22 · Foundation · ~10 minutes · Home · OOP (Object-Oriented Programming) ladder · Roadmap

Today's win: say what a static field and static method are, and why a static method cannot use this.

Class variables

"Fields that have the static modifier in their declaration are called static fields or class variables. They are associated with the class, rather than with any object. Every instance of the class shares a class variable, which is in one fixed location in memory."[1]

Class methods

"Class methods cannot access instance variables or instance methods directly; they must use an object reference. Also, class methods cannot use the this keyword as there is no instance for this to refer to."[1] Constants combine static and final, conventionally UPPER_CASE.[1]

java oop/examples/StaticMembers.java
before: 0
after 3 objects, shared count = 3
instance ids: 1, 2, 3
constant: 100

One shared counter, but a separate id per object. Source: StaticMembers.java. Design warning: mutable static state is global state, which makes code hard to test (see the Singleton lesson).

static final defines a constant.[1]

The demo printed a shared count of 3.
