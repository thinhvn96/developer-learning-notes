Class, instance và constructor

OOP (Lập trình hướng đối tượng) · Bài 0002 · bước 2/22 · Foundation · ~10 phút · Trang chủ · Lộ trình OOP · Lộ trình tổng · English

Thành quả hôm nay: giải thích được sự khác nhau giữa class và instance, giữa reference và object, và cách nối constructor (constructor chaining) bằng this(...).

Bản thiết kế và các instance

"Class là bản thiết kế (blueprint) để từ đó tạo ra từng object cụ thể." Chiếc xe đạp của bạn là một instance của class xe đạp: mỗi instance có giá trị field riêng (state của nó), còn method thì đến từ class.[1]

Reference

Một biến giữ reference (tham chiếu) tới object, chứ không phải chính object đó. Hai biến có thể cùng trỏ tới một object (gọi là alias), nên thay đổi state qua biến này sẽ thấy được qua biến kia.

java oop/examples/ClassAndInstances.java
gear=1 speed=10
gear=3 speed=25
a after alias.speedUp(1): 11   b unchanged: 25
a == alias: true, a == b: false

a và b là hai object riêng biệt với state riêng; alias là reference thứ hai trỏ tới object của a (a == alias là true). Constructor không tham số ủy quyền bằng this(1, 0), nên logic khởi tạo chỉ nằm ở một chỗ. Mã nguồn: ClassAndInstances.java. Đây cũng chính là vấn đề reference so với equality nằm sau bài equals và hashCode.

Luyện truy hồi

Trả lời theo trí nhớ. Mỗi câu chỉ một lần chọn.

1. Class là...?

Class là bản thiết kế để từ đó tạo ra từng object cụ thể.[1]

2. Hai reference trỏ tới một object. Đổi qua một cái thì sao?

Chúng là alias của cùng một object; demo cho thấy speed của a thay đổi qua alias.

3. this(1, 0) trong constructor làm gì?

Constructor chaining ủy quyền cho một constructor khác của cùng class.

4. Các instance có dùng chung giá trị field không?

Mỗi instance có state riêng; trong demo b vẫn là 25 trong khi a thay đổi.
