Enums as classes

OOP (Object-Oriented Programming) · Lesson 0013 · step 13 of 22 · Advanced · ~10 minutes · Home · OOP (Object-Oriented Programming) ladder · Roadmap

Today's win: use an enum with fields, constructors and constant-specific methods as a type-safe set of instances.

What an enum is

"An enum type is a special data type that enables for a variable to be a set of predefined constants." Enums can have fields, methods and constructors (which must be package-private or private) and give compile-time type safety. "All enums implicitly extend java.lang.Enum", so an enum cannot extend anything else.[1] Use them "any time you need to represent a fixed set of constants".[1]

java oop/examples/EnumsAsClasses.java
MERCURY  gravity 3.70
EARTH    gravity 9.80
ADD 6,7 -> 13
MUL 6,7 -> 42
valueOf("EARTH") == Planet.EARTH : true
EnumMap: {ADD=2}
no such constant: No enum constant EnumsAsClasses.Planet.PLUTO

Planet carries data; Op gives each constant its own behavior (a tiny strategy per constant); EnumMap is an efficient map keyed by enum. Compare with sealed hierarchies when each variant needs different data (JDK 17 lesson). Source: EnumsAsClasses.java.

Retrieval practice

Answer from memory. One attempt each.

1. An enum is a fixed set of...?

A set of predefined constants (instances).[1]

2. Enum constructors may be...?

Constructors must be package-private or private.[1]

3. Can an enum extend another class?

It implicitly extends java.lang.Enum.[1]

4. Constant-specific method bodies give...?

Op.ADD and Op.MUL each implemented apply differently.
