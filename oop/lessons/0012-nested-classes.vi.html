Nested, inner, local và anonymous class

OOP (Lập trình hướng đối tượng) · Bài 0012 · bước 12/22 · Advanced · ~10 phút · Trang chủ · Lộ trình OOP · Lộ trình tổng · English

Thành quả hôm nay: chọn được giữa static nested, inner, local và anonymous class, và nói được mỗi loại truy cập được những gì.

Hai nhóm

Inner class (không static) gắn với một instance của class bao ngoài và "có quyền truy cập các member khác của class bao ngoài, kể cả khi chúng được khai báo private". Static nested class không truy cập được member của instance bao ngoài và hoạt động giống một class top-level, chỉ được lồng vào cho tiện việc đóng gói.[1]

Lý do để lồng class: gom nhóm logic các class chỉ dùng ở một chỗ, tăng tính đóng gói ("khi giấu class B bên trong class A, các member của A có thể khai báo private mà B vẫn truy cập được"), và code dễ đọc hơn vì nằm gần nơi được dùng.[1]

java oop/examples/NestedClasses.java
inner sees outer's private field      : 7
static nested sees only static members : 99
local class: 15, anonymous comparator sorted: [a, bb, ccc]

Local class và anonymous class có thể capture biến cục bộ là final hoặc effectively final (cùng quy tắc với lambda: bài học). Với interface chỉ có một method, hãy ưu tiên lambda thay vì anonymous class; pattern Builder dùng một static nested class (bài học). Mã nguồn: NestedClasses.java.

Luyện truy hồi

Trả lời theo trí nhớ. Mỗi câu chỉ một lần chọn.

1. Inner class có truy cập được member private của class ngoài không?

Inner class truy cập được, kể cả khi là private.[1]

2. Static nested class có cần một instance của class ngoài không?

Nó hoạt động như class top-level được lồng vào cho tiện đóng gói.[1]

3. Một lý do để lồng class?

Gom nhóm logic các class chỉ dùng ở một chỗ.[1]

4. Biến cục bộ được capture phải là...?

Demo capture một biến int effectively final.
