OOP (Lập trình hướng đối tượng): từ cơ bản đến nâng cao

Trang chủ · Lộ trình OOP · Hỏi đáp phỏng vấn · Lộ trình tổng · 22 bài · English

Object, kế thừa, polymorphism, interface, composition và các nguyên lý SOLID, mỗi bài đều có một ví dụ Java chạy được. 22 bài theo thứ tự nên đọc, học xong bài nào thì đánh dấu bài đó (chỉ lưu trong trình duyệt này). Các thư mục: lessons/, exercises/, examples/.

Foundation

  1. Object: state, behavior và encapsulation
  2. Class, instance và constructor
  3. Access level: che giấu những gì cần che giấu
  4. Static member: state dùng chung và hằng số

Core

  1. Kế thừa: extends, super và quan hệ is-a
  2. Thứ tự khởi tạo: static block, field, constructor
  3. Override và hiding
  4. Polymorphism và cơ chế gọi virtual method
  5. Abstract class và interface
  6. Interface như một hợp đồng
  7. Ưu tiên composition hơn kế thừa

Advanced

  1. Nested, inner, local và anonymous class
  2. Enum cũng là class
  3. Immutability và defensive copy
  4. Coupling và cohesion
  5. Law of Demeter
  6. SOLID 1: Single Responsibility Principle
  7. SOLID 2: Open/Closed Principle
  8. SOLID 3: Liskov Substitution Principle
  9. SOLID 4: Interface Segregation Principle
  10. SOLID 5: Dependency Inversion Principle

Senior

  1. God object và refactor hướng tới SOLID

Dự kiến

  • Thiết kế dựa trên generic và bounded type trong API (dự kiến)
  • Equality, hashing và identity của object trong domain modeling (dự kiến)
  • Thuật ngữ domain-driven design (entity, value object, aggregate): cần thêm nguồn (dự kiến)
