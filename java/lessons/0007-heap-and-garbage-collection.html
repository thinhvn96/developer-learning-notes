Heap sizing and garbage collection

Java (JDK 8, 17, 21) · Lesson 0007 · step 18 of 27 · Senior · ~12 minutes · Home · Java (JDK 8, 17, 21) ladder · Roadmap

Today's win: state the default heap size and collector rules, read one line of a GC log, and know which knob to turn first.

What the GC does

The garbage collector allocates memory, hands it to the application, "determines which parts of that memory is still in use", and reclaims the rest.[1] HotSpot collectors use "generational scavenging in conjunction with aging" to concentrate effort where reclaimable memory is most likely.[1]

Defaults you should be able to recite

  • Collector: G1 on a "server-class machine" (two or more processors and at least 1792 MB physical memory), otherwise the Serial collector.[2]
  • Initial heap: 1/64 of physical memory. Maximum heap: 1/4 of physical memory.[2]
  • -XX:MaxRAMPercentage sets the maximum heap as a percentage of the max memory the JVM sees; default 25 percent.[3]

Read a GC log line

java -Xmx64m -Xlog:gc java/examples/GcDemo.java
[0.001s][info][gc] Using G1
max heap (MB): 64
[0.278s][info][gc] GC(0) Pause Young (Normal) (G1 Evacuation Pause) 24M->3M(64M) 2.547ms

Reading it: collection number 0, a young-generation pause, heap occupancy went from 24 MB to 3 MB out of 64 MB, taking 2.5 ms. The demo allocates short-lived arrays, so almost everything is reclaimed. (Log format is from running the example on this machine with JDK 21.)

Interview move: before touching collector flags, set the heap size on purpose (-Xmx or MaxRAMPercentage) and turn on GC logging. The Docker and Kubernetes lessons revisit this: heap is only part of a container's memory.

Retrieval practice

Answer from memory. One attempt each.

1. Default maximum heap without flags?

The maximum heap defaults to 1/4 of physical memory.[2]

2. Which collector is the default on a server-class machine?

G1 on server-class machines, Serial otherwise.[2]

3. Server-class means at least how much?

Two or more processors and physical memory of at least 1792 MB.[2]

4. Log shows 24M->3M(64M). What is 64M?

Before -> after (total heap capacity).
