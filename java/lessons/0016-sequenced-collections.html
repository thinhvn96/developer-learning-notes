JDK 21: sequenced collections

Java (JDK 8, 17, 21) · Lesson 0016 · step 25 of 27 · Core · ~10 minutes · Home · Java (JDK 8, 17, 21) ladder · Roadmap

Today's win: use getFirst, getLast and reversed on lists, deques and ordered sets and maps, and name the three new interfaces.

The gap it fills (final in JDK 21)

JEP 431 introduces "new interfaces to represent collections with a defined encounter order". Before it, reverse iteration and end-element access differed across List, Deque, SortedSet and LinkedHashSet.[1]

InterfaceKey methods[1]
SequencedCollection<E>reversed(), addFirst, addLast, getFirst, getLast, removeFirst, removeLast
SequencedSet<E>extends Set and SequencedCollection; covariant reversed()
SequencedMap<K,V>reversed(), putFirst, putLast, firstEntry, lastEntry, pollFirstEntry, pollLastEntry, sequenced views
java java/examples/jdk21/Jdk21Features.java
a c [c, b, a]                       # list.getFirst(), getLast(), reversed()
one=1 two=2 {two=2, one=1}          # firstEntry(), lastEntry(), reversed() of a LinkedHashMap

This is why lesson 2 mentions getFirst and getLast in the ArrayList Javadoc: those methods are documented there in the current API. On JDK 17 you would write list.get(list.size() - 1).

Retrieval practice

Answer from memory. One attempt each.

1. Which interface adds putFirst and putLast?

SequencedMap has putFirst, putLast and related methods.[1]

2. Method returning a reverse-ordered view?

reversed() returns a reverse-ordered view.[1]

3. Which JDK finalized sequenced collections?

Finalized in Java 21.[1]

4. Does a plain HashSet have an encounter order guarantee?

Only collections with a defined encounter order are sequenced; HashSet is not one (see the HashMap lesson on ordering).
