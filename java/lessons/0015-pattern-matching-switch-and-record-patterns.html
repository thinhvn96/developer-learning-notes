JDK 21: pattern matching for switch and record patterns

Java (JDK 8, 17, 21) · Lesson 0015 · step 24 of 27 · Advanced · ~12 minutes · Home · Java (JDK 8, 17, 21) ladder · Roadmap

Today's win: write a JDK 21 switch that destructures records, uses when guards and case null, and needs no default on a sealed type.

Pattern matching for switch (final in JDK 21)

  • Type patterns in case labels test the selector against several patterns with an action for each.[1]
  • Guards: case String s when s.equalsIgnoreCase("YES") -> ... refines a pattern with when.[1]
  • Null: "If the selector expression evaluates to null then any null case label is said to match." Without case null the switch still throws NullPointerException, as before.[1]
  • Exhaustive: pattern switches must cover all cases; for sealed types the compiler checks coverage from the permitted subtypes, sometimes removing the need for default.[1]
  • Dominance: a label may not be dominated by an earlier one, so put more specific patterns first (like ordering catch clauses).[1]

Record patterns (final in JDK 21)

They "deconstruct record values", and can nest: Rectangle(ColoredPoint(Point(var x, var y), var c), var lr).[2]

static String describe(Shape s) {
    return switch (s) {
        case Circle(Point(var x, var y), var r) when r > 100 -> "huge circle at " + x + "," + y;
        case Circle(Point(var x, var y), var r)              -> "circle r=" + r;
        case Rect(Point(var x1, var y1), Point(var x2, var y2)) -> "rect " + (x2 - x1) + "x" + (y2 - y1);
    };
}

Source: Jdk21Features.java. Compiling it with --release 17 fails with "patterns in switch statements are not supported in -source 17", which is a handy interview fact: this is a 21 feature.

Answer from memory. One attempt each.

1. Selector is null and there is no case null. Result?

Without a null case the switch throws NPE as before.[1]

2. What does a when clause add?

Guards refine a pattern case label.[1]

3. Sealed selector, all subtypes covered. Default needed?

The compiler checks coverage for sealed types, sometimes removing default.[1]

4. Which patterns can be nested?

Record patterns and type patterns can be nested.[2]
