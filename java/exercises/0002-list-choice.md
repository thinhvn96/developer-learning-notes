# Exercise 0002: pick the collection

[Tiếng Việt](0002-list-choice.vi.md)

Companion to [lesson 2](../lessons/0002-choosing-a-list.html). For each requirement, name the class and cite the Javadoc sentence that justifies it. Say your answers to the teacher before checking.

1. A browser-history "back" stack, single thread.
2. A work queue where producers add at the tail and one consumer removes from the head, single thread.
3. A list you read by index thousands of times and append to occasionally.
4. Remove all even numbers from a `List<Integer>` while iterating. Write two correct versions (`removeIf`, and an explicit `Iterator`).

Interview follow-up to rehearse aloud: "When would you actually choose `LinkedList`?" Keep the answer honest: name a concrete need and admit when there is none.
