# Bài tập 0012: review code với var và text block

Đi kèm [bài 12](../lessons/0012-var-and-text-blocks.vi.html). · [English](0012-var-and-text-block-review.md)

Lấy một method có chuỗi JSON dài được ghép bằng phép nối chuỗi và các khai báo dài dòng (`Map<String, List<Integer>> m = new HashMap<String, List<Integer>>();`). Viết lại bằng text block và `var`. Sau đó liệt kê hai chỗ mà `var` sẽ làm code khó đọc hơn và một chỗ bắt buộc không được dùng nó.
