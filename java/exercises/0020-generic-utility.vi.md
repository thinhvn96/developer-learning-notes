# Bài tập 0020

Đi kèm [bài 20](../lessons/0020-generics-basics-and-invariance.vi.html). · [English](0020-generic-utility.md)

Viết `static <T> T firstOrDefault(List<T> list, T def)` và `Pair<A,B>` dưới dạng record. Sau đó giải thích trong hai câu vì sao `List<Object> l = new ArrayList<String>();` không biên dịch được.

Nói dự đoán của bạn cho giáo viên trước khi chạy bất cứ thứ gì.
