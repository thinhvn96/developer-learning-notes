# Exercise 0012: review with var and text blocks

[Tiếng Việt](0012-var-and-text-block-review.vi.md)

Companion to [lesson 12](../lessons/0012-var-and-text-blocks.html).

Take a method with a long JSON string built by concatenation and verbose declarations (`Map<String, List<Integer>> m = new HashMap<String, List<Integer>>();`). Rewrite with text block and `var`. Then list two places where `var` would hurt readability and one place where it must not be used.
