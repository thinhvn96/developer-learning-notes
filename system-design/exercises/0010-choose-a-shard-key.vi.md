# Bài tập 0010

Đi kèm [bài 10](../lessons/0010-sharding.vi.html). · [English](0010-choose-a-shard-key.md)

Với các table orders, users và events, hãy đề xuất shard key và chiến lược. Cái gì sẽ hỏng nếu dùng `created_at` làm key? Thêm một shard và tính lượng dữ liệu phải di chuyển với mod-N so với consistent hashing.
