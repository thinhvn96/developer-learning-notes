Adapter

Design Patterns · Bài 0009 · bước 9/30 · Core · ~10 phút · Trang chủ · Lộ trình Design Patterns · Lộ trình tổng · English

Thành quả hôm nay: bọc một class không tương thích để nó khớp với interface mà client mong đợi, và nhận ra Arrays.asList chính là một adapter.

Mục đích

Adapter là "một structural design pattern cho phép các object có interface không tương thích làm việc được với nhau." Hãy dùng nó khi bạn muốn dùng một class có sẵn nhưng interface của nó không khớp với code của bạn, hoặc khi muốn tái sử dụng nhiều subclass vốn thiếu một chức năng chung.[1]

Ví dụ

java design-patterns/examples/AdapterDemo.java
legacy printed 5 bytes: hello
array=[x, y, c] view=[x, y, c]
fixed-size: add() unsupported

LegacyAdapter implement Printer mà client mong đợi và dịch lời gọi sang method với tham số khác của class legacy. Trong JDK, Arrays.asList "đóng vai trò cầu nối giữa API dựa trên mảng và API dựa trên collection": một list kích thước cố định được mảng đứng sau, ghi xuyên qua theo cả hai chiều (như ở trên); gọi add sẽ ném UnsupportedOperationException.[2] Mã nguồn: AdapterDemo.java.

Ưu và nhược điểm

Ưu điểm

  • Tách việc chuyển đổi interface hoặc dữ liệu khỏi business logic
  • Có thể thêm adapter mới mà không làm hỏng code phía client

Nhược điểm

  • Thêm interface và class; đôi khi sửa thẳng class service lại đơn giản hơn

(Theo trang mô tả pattern.)[1] Adapter dùng để chắp vá cho class có sẵn (còn Bridge được thiết kế từ đầu); Decorator giữ nguyên hoặc mở rộng interface trong khi Adapter thay đổi nó; Proxy giữ interface y hệt; Facade định nghĩa một interface mới cho cả một subsystem, còn Adapter thường chỉ bọc một object.

Luyện truy hồi

Trả lời theo trí nhớ. Mỗi câu chỉ một lần chọn.

1. Mục đích của Adapter?

Các object có interface không tương thích làm việc được với nhau.[1]

2. Arrays.asList là...?

Thay đổi đi xuyên xuống mảng (thấy rõ trong lần chạy).[2]

3. Adapter so với Facade?

Adapter thường bọc một object; Facade bọc cả một subsystem.[1]

4. Một cái giá của Adapter?

Độ phức tạp tổng thể tăng lên.[1]
