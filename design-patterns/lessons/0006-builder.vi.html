Builder

Design Patterns · Bài 0006 · bước 6/30 · Core · ~10 phút · Trang chủ · Lộ trình Design Patterns · Lộ trình tổng · English

Thành quả hôm nay: thay một telescoping constructor bằng builder và validate trong build().

Mục đích

Builder là "một creational design pattern cho phép bạn dựng các object phức tạp theo từng bước." Nó giải quyết vấn đề telescoping constructor (constructor có quá nhiều tham số tùy chọn), dựng ra các dạng biểu diễn khác nhau bằng cùng một chuỗi bước, và dựng cây composite mà không để lộ product còn dang dở.[1]

Ví dụ

java design-patterns/examples/BuilderDemo.java
Pizza(large, cheese=true, pepperoni=false, mushrooms=true, olives=false, extra=2)
Pizza(large, cheese=true, pepperoni=false, mushrooms=true, olives=false, extra=2)
StringBuilder is the JDK's best-known builder: a1!
build() validates: size is required

So sánh lời gọi constructor với builder kiểu fluent: chỉ những bước bạn cần mới phải viết ra, và build() là nơi duy nhất để validate. Mã nguồn: BuilderDemo.java. Builder ở đây là một static nested class (bài OOP). Trong JDK: StringBuilder và HttpRequest.newBuilder(); với dữ liệu immutable đơn giản, record cộng với compact constructor (bài học) thường là đủ.

Ưu và nhược điểm

Ưu điểm

  • Dựng từng bước, có thể hoãn lại hoặc đệ quy
  • Tái sử dụng code dựng object cho nhiều dạng biểu diễn
  • Cô lập logic dựng phức tạp (Single Responsibility)

Nhược điểm

  • Thêm class và code phức tạp hơn

(Theo trang mô tả pattern.)[1] Factory Method đơn giản hơn nhưng kém linh hoạt hơn; Abstract Factory trả product về ngay, còn Builder cho phép thêm bước; Builder đi cùng Composite để dựng cây.

Luyện truy hồi

Trả lời theo trí nhớ. Mỗi câu chỉ một lần chọn.

1. Builder giải quyết vấn đề nào?

Constructor tích tụ quá nhiều tham số tùy chọn.[1]

2. Validate ở đâu?

Bản demo ném exception từ build() khi size bị bỏ trống.

3. Builder so với Abstract Factory?

Abstract Factory trả product về ngay; Builder cho phép thêm các bước bổ sung.[1]

4. Cái giá phải trả?

Nó làm code phức tạp hơn vì phải thêm class mới.[1]
