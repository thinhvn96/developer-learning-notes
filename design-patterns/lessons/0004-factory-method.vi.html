Factory Method

Design Patterns · Bài 0004 · bước 4/30 · Core · ~10 phút · Trang chủ · Lộ trình Design Patterns · Lộ trình tổng · English

Thành quả hôm nay: giải thích được cách một creator giao việc chọn product cụ thể cho các subclass, và nhận ra các static factory method trong JDK.

Mục đích

Factory Method là "một creational design pattern cung cấp interface để tạo object trong superclass, nhưng cho phép subclass thay đổi kiểu object sẽ được tạo ra." Hãy dùng nó khi bạn không biết trước chính xác code của mình sẽ làm việc với những kiểu nào, khi bạn muốn cho người dùng library hoặc framework mở rộng các thành phần bên trong, hoặc khi muốn tái sử dụng các object có sẵn.[1]

Ví dụ

Dialog.render() được viết một lần dựa trên interface Button; mỗi subclass override createButton() để chọn product.

java design-patterns/examples/FactoryMethodDemo.java
WindowsDialog renders [Windows button]
WebDialog renders <button>
List.of(...) returns a List; concrete class chosen by the JDK: List12

Mã nguồn: FactoryMethodDemo.java. Người anh em bạn gặp hằng ngày: các static factory method như List.of(..) và Integer.valueOf, nơi caller nhận về một kiểu interface còn JDK tự chọn class (lần chạy của tôi ra List12).

Ưu và nhược điểm

Ưu điểm

  • Giảm phụ thuộc giữa creator và các product cụ thể
  • Single Responsibility: code tạo object nằm ở một chỗ
  • Open/Closed: thêm loại product mới mà không sửa code cũ

Nhược điểm

  • Code phức tạp hơn: phát sinh nhiều subclass mới

(Theo trang mô tả pattern.)[1] Nó thường phát triển dần thành Abstract Factory, Prototype hoặc Builder, và có liên quan đến Template Method (factory method thường là một bước trong một template method).

Luyện truy hồi

Trả lời theo trí nhớ. Mỗi câu chỉ một lần chọn.

1. Trong Factory Method, ai quyết định product cụ thể?

Subclass thay đổi kiểu object được tạo ra.[1]

2. Lợi ích?

Nó loại bỏ sự phụ thuộc chặt giữa creator và các product cụ thể.[1]

3. Nhược điểm?

Độ phức tạp của code tăng theo số subclass mới.[1]

4. Ví dụ factory method trong JDK?

List.of trả về một List mà class cụ thể do JDK chọn.
