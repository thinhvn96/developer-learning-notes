Decorator

Design Patterns · Lesson 0012 · step 12 of 30 · Core · ~10 minutes · Home · Design Patterns ladder · Roadmap · Tiếng Việt

Today's win: add behavior by wrapping an object in another object with the same interface, and recognize JDK decorators.

Intent

Decorator is "a structural design pattern that lets you attach new behaviors to objects by placing these objects inside special wrapper objects that contain the behaviors." Use it to assign extra behaviors at runtime without breaking existing code, and when extension by inheritance is awkward or impossible (final classes).[1]

Example

java design-patterns/examples/DecoratorDemo.java
espresso + sugar + milk = 4
espresso + sugar + sugar = 3
BufferedReader: line1 | line2
unmodifiable view reads through: [a, b]
writes rejected by the wrapper

Each decorator implements Coffee and holds a Coffee, adding to description and cost; stacks can repeat. JDK decorators: BufferedReader wraps any reader ("reads text from a character-input stream, buffering characters"),[2] and Collections.unmodifiableList returns a wrapper whose reads "read through" to the backing list while modifications throw UnsupportedOperationException[3] (a wrapper/view: I classify it as a decorator-style wrapper). Source: DecoratorDemo.java.

Pros and cons

Pros

  • Extend behavior without new subclasses
  • Add or remove responsibilities at runtime
  • Combine behaviors by stacking wrappers
  • Small, focused classes

Cons

  • Hard to remove a specific wrapper from the stack
  • Behavior can depend on stacking order
  • Configuration code can get messy

(From the pattern's page.)[1] Adapter changes the interface, Decorator keeps or extends it, Proxy keeps it identical; Strategy changes an object's 'guts', Decorator its 'skin'.

Retrieval practice

Answer from memory. One attempt each.

1. A decorator implements...?

It wraps an object while keeping the interface.[1]

2. Decorator vs Strategy?

Strategy changes the guts; Decorator changes the skin.[1]

3. JDK decorator?

BufferedReader wraps another reader.[2]

4. Downside?

Behavior may depend on wrapper order.[1]
