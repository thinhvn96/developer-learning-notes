Retrieval practice

Answer from memory. One attempt each.

1. JDK singleton?

Every Java application has a single Runtime instance.[1]

2. JDK strategy?

Comparators are passed to sort to choose the order.[4]

3. JDK adapter?

It bridges array and collection APIs.[3]

4. JDK visitor?

Passed to Files.walkFileTree to visit each file.[7]
