State

Design Patterns · Bài 0022 · bước 22/30 · Core · ~10 phút · Trang chủ · Lộ trình Design Patterns · Lộ trình tổng · English

Thành quả hôm nay: thay các câu điều kiện phụ thuộc trạng thái bằng các state object tự kích hoạt việc chuyển trạng thái của chính nó.

Mục đích

State là "một behavioral design pattern cho phép một object thay đổi hành vi khi trạng thái bên trong của nó thay đổi." Nó gắn liền với máy trạng thái hữu hạn (finite-state machine): đưa hành vi của từng trạng thái vào class riêng và để context ủy quyền cho state object hiện tại. Hãy dùng nó khi một object hành xử khác nhau ở nhiều trạng thái, hoặc khi một class bị ngập trong các khối điều kiện to đùng.[1]

Ví dụ

java design-patterns/examples/StateDemo.java
draft: sending to moderation
  state -> Moderation
moderation: approved, publishing
  state -> Published
published: already public, ignoring
published: already public, ignoring
published: cannot reject a public document

Cùng một lời gọi publish() nhưng làm những việc khác nhau ở Draft, Moderation và Published, và mỗi trạng thái tự quyết định trạng thái kế tiếp. Mã nguồn: StateDemo.java. Khác biệt then chốt so với Strategy: "các trạng thái cụ thể có thể biết về nhau và tự khởi phát việc chuyển từ trạng thái này sang trạng thái khác, trong khi các strategy hầu như không bao giờ biết về nhau."[1] Với một tập trạng thái nhỏ và cố định, một enum có hành vi riêng cho từng hằng là lựa chọn nhẹ nhàng hơn.

Ưu và nhược điểm

Ưu điểm

  • Single Responsibility và Open/Closed
  • Loại bỏ các khối điều kiện cồng kềnh

Nhược điểm

  • Quá tay khi chỉ có vài trạng thái hoặc hiếm khi thay đổi

(Theo trang mô tả pattern.)[1] State, Strategy và Bridge có chung cấu trúc dựa trên composition nhưng giải quyết các vấn đề khác nhau.

Luyện truy hồi

Trả lời theo trí nhớ. Mỗi câu chỉ một lần chọn.

1. State thay đổi cái gì?

Object thay đổi hành vi khi trạng thái của nó thay đổi.[1]

2. State so với Strategy?

State có thể tự khởi phát việc chuyển trạng thái; các strategy hầu như không biết về nhau.[1]

3. Thay thế cho...?

Nó loại bỏ if/switch phụ thuộc trạng thái.[1]

4. Gọi publish() trên document đã Published trong demo?

Demo in ra 'already public, ignoring'.
