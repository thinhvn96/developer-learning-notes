Prototype

Design Patterns · Bài 0007 · bước 7/30 · Core · ~10 phút · Trang chủ · Lộ trình Design Patterns · Lộ trình tổng · English

Thành quả hôm nay: sao chép một object đã được cấu hình sẵn, và biết chọn giữa shallow copy với deep copy.

Mục đích

Prototype là "một creational design pattern cho phép bạn sao chép các object có sẵn mà code không phải phụ thuộc vào class của chúng." Hãy dùng nó khi code không nên phụ thuộc vào các class cụ thể mà nó sao chép, hoặc để tránh tạo ra những subclass chỉ khác nhau ở phần khởi tạo, bằng cách clone các object đã cấu hình sẵn.[1]

Ví dụ

java design-patterns/examples/PrototypeDemo.java
template : orc(hp=100, items=[club, shield])
shallow  : orc-2(hp=100, items=[club, shield])   <- shares the SAME list object
deep     : orc-3(hp=100, items=[club])   <- has its own list

Bản shallow copy dùng chung list với template, nên thay đổi sau này trên template sẽ hiện ra cả ở bản sao; bản deep copy có list riêng của nó. Cơ chế có sẵn của Java là Cloneable/Object.clone; copy constructor hoặc copy method (như ở đây) thường rõ ràng hơn (đây là khuyến nghị của tôi; trang mô tả pattern không gắn với ngôn ngữ nào). Mã nguồn: PrototypeDemo.java. Liên quan: immutability và defensive copy.

Ưu và nhược điểm

Ưu điểm

  • Clone object mà không phụ thuộc class cụ thể của nó
  • Tránh khởi tạo lặp lại bằng cách clone từ template
  • Thay thế cho kế thừa khi cần các bộ cấu hình dựng sẵn

Nhược điểm

  • Sao chép object phức tạp có tham chiếu vòng rất khó

(Theo trang mô tả pattern.)[1] Nó có thể thay Memento cho các snapshot trạng thái đơn giản, giúp Command lưu lịch sử, và tăng tốc các thiết kế dùng nhiều Composite/Decorator bằng cách clone cả cấu trúc.

Luyện truy hồi

Trả lời theo trí nhớ. Mỗi câu chỉ một lần chọn.

1. Prototype tạo object bằng cách...?

Nó sao chép object có sẵn mà không phụ thuộc vào class của chúng.[1]

2. Shallow copy của một field kiểu list thì dùng chung...?

Bản shallow copy trong demo thấy được phần tử mà template thêm vào sau đó.

3. Trường hợp khó với prototype?

Nhân bản object phức tạp có tham chiếu vòng là việc khó.[1]

4. Lợi ích?

Clone từ template dựng sẵn giúp bỏ được việc khởi tạo lặp đi lặp lại.[1]
