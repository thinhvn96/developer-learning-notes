Những pattern bạn vẫn đang dùng trong JDK

Design Patterns · Bài 0027 · bước 27/30 · Core · ~10 phút · Trang chủ · Lộ trình Design Patterns · Lộ trình tổng · English

Thành quả hôm nay: kể ra một ví dụ trong JDK cho mỗi pattern trong khoảng một chục pattern, và chạy thử chúng.

Biết pattern ẩn ở đâu trong code bạn vẫn dùng hằng ngày giúp câu trả lời phỏng vấn trở nên cụ thể.

Luyện truy hồi

Trả lời theo trí nhớ. Mỗi câu chỉ một lần chọn.

1. Singleton trong JDK?

Mỗi ứng dụng Java có đúng một instance Runtime.[1]

2. Strategy trong JDK?

Comparator được truyền vào sort để chọn thứ tự.[4]

3. Adapter trong JDK?

Nó làm cầu nối giữa API mảng và API collection.[3]

4. Visitor trong JDK?

Được truyền vào Files.walkFileTree để ghé thăm từng file.[7]
