Externalized configuration, thứ tự ưu tiên và profile

Spring Boot · Bài 0008 · bước 5/13 · Core · ~10 phút · Trang chủ · Lộ trình Spring Boot · Lộ trình tổng · English

Thành quả hôm nay: đoán đúng giá trị nào thắng khi cùng một property được đặt trong file, trong file của profile, và trong một nguồn có độ ưu tiên cao hơn.

Thứ tự ưu tiên (cái sau ghi đè cái trước)

  1. default properties
  2. @PropertySource
  3. các file config data (application.properties/.yaml)
  4. giá trị random
  5. biến môi trường của OS
  6. Java system properties
  7. JNDI, servlet init params
  8. SPRING_APPLICATION_JSON
  9. tham số dòng lệnh (cao nhất)[1]

Đó là lý do cùng một JAR chạy được ở mọi môi trường: file chứa giá trị mặc định, còn ConfigMap/env var của Kubernetes hoặc tham số dòng lệnh sẽ ghi đè chúng (bài về ConfigMap).

Profile

Profile "tách riêng các phần cấu hình của ứng dụng và chỉ cho chúng có hiệu lực ở một số môi trường nhất định". Đánh dấu bean bằng @Profile("production"); kích hoạt bằng spring.profiles.active=dev (qua property hoặc dòng lệnh). Khi không có profile nào được kích hoạt, profile default sẽ được bật.[2] Một file profile như application-dev.properties sẽ thêm hoặc ghi đè giá trị khi profile đó active (quy ước đặt tên này được dùng trong demo project và đã chạy đúng).

RESULT default profile: name=demo-app greeting=hello bean=default-profile bean
RESULT dev profile:     name=demo-app greeting=hello from the dev profile bean=dev-profile bean
RESULT dev profile + test property: greeting=from a higher-precedence source

Code: ConfigAndProfileTest.java, application-dev.properties, GreetingConfig.java. Trường hợp cuối đặt property ngay trong annotation của test (một nguồn có độ ưu tiên cao hơn file profile) và nó thắng.

Đã kiểm chứng: project trong examples/demo-app (Spring Boot 4.1.1, JDK 21, tạo bằng Spring Initializr) đã được build và chạy test trong một Maven container; các dòng đánh dấu RESULT lấy từ chính những test đó. Tự chạy thử: cd spring-boot/examples/demo-app && ./mvnw test (hoặc dùng image maven:3-eclipse-temurin-21).

Luyện truy hồi

Trả lời theo trí nhớ. Mỗi câu chỉ một lần chọn.

1. Nguồn có độ ưu tiên cao nhất?

Tham số dòng lệnh ghi đè mọi thứ đứng trước nó trong danh sách.[1]

2. Env var so với application.properties. Cái nào thắng?

Biến môi trường của OS đứng sau trong thứ tự.[1]

3. Property dùng để kích hoạt profile?

spring.profiles.active kích hoạt các profile.[2]

4. Không có profile nào active. Profile nào được bật?

Một profile tên là default sẽ được bật.[2]
