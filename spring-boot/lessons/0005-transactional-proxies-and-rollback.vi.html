@Transactional: proxy và quy tắc rollback

Spring Boot · Bài 0005 · bước 9/13 · Advanced · ~12 phút · Trang chủ · Lộ trình Spring Boot · Lộ trình tổng · English

Thành quả hôm nay: đoán đúng một method @Transactional có thực sự chạy trong transaction hay không và có rollback hay không, với ba cái bẫy kinh điển.

Các giá trị mặc định cần thuộc

Thuộc tínhMặc định[1]
PropagationREQUIRED
Isolationmặc định của database (ISOLATION_DEFAULT)
Read-write?read-write
Rollback khi gặpRuntimeException và Error; không rollback với checked exception

Ba cái bẫy

  1. Checked exception vẫn commit. Ném một checked Exception mặc định không gây rollback. Hãy dùng @Transactional(rollbackFor = Exception.class).[1]
  2. Self-invocation bị bỏ qua. Ở chế độ proxy mặc định, chỉ các lời gọi từ bên ngoài đi qua proxy mới bị chặn lại xử lý; một method gọi method khác trên cùng object sẽ không kích hoạt xử lý transaction.[1]
  3. Visibility. Method private không bao giờ có transaction; với proxy dựa trên interface thì chỉ method public mới có.[1]

Tài liệu reference nêu chế độ AspectJ là phương án thay thế nếu bạn cần self-invocation hoạt động.[1] Đoạn code mẫu: TransactionalPitfalls.java.

Đã kiểm chứng

RESULT checked exception, default rules         -> accounts saved: 1
RESULT checked exception, rollbackFor=Exception -> accounts saved: 0
RESULT runtime exception, default rules         -> accounts saved: 0
RESULT external call through the proxy          -> accounts saved: 0
RESULT self-invocation (this.method())          -> accounts saved: 2

Code: BankService.java và TransactionBehaviourTest.java. Hai dòng cuối là cùng một method: gọi qua proxy thì cả hai lần save đều bị rollback; gọi dưới dạng this.createTwoThenFail(...) thì cả hai vẫn được commit.

Liên hệ với PostgreSQL: thuộc tính isolation tương ứng với các mức trong bài về isolation của PostgreSQL, và mặc định là mức mặc định của chính database (Read committed trên PostgreSQL).

Đã kiểm chứng: project trong examples/demo-app (Spring Boot 4.1.1, JDK 21, tạo bằng Spring Initializr) đã được build và chạy test trong một Maven container; các dòng đánh dấu RESULT lấy từ chính những test đó. Tự chạy thử: cd spring-boot/examples/demo-app && ./mvnw test (hoặc dùng image maven:3-eclipse-temurin-21).

Luyện truy hồi

Trả lời theo trí nhớ. Mỗi câu chỉ một lần chọn.

1. Mặc định cái gì kích hoạt rollback?

RuntimeException và Error kích hoạt rollback; checked exception thì không.[1]

2. Một method gọi method khác qua this. Transaction có được áp dụng không?

Self-invocation không kích hoạt quản lý transaction ở chế độ proxy.[1]

3. Muốn checked exception cũng rollback thì dùng?

rollbackFor = Exception.class khiến mọi exception đều kích hoạt rollback.[1]

4. Propagation mặc định?

PROPAGATION_REQUIRED là mặc định.[1]
