Bean Validation và response 400

Spring Boot · Bài 0010 · bước 8/13 · Core · ~10 phút · Trang chủ · Lộ trình Spring Boot · Lộ trình tổng · English

Thành quả hôm nay: validate request body bằng Bean Validation và biết client sẽ nhận status nào.

Constraint trên model

Bean Validation cho phép bạn khai báo constraint trên model và thực thi chúng lúc runtime: @NotNull, @Size(max = 64), @Min(0) và nhiều thứ khác.[1]

public record PersonRequest(@NotBlank String name, @Min(0) int age) { }

@PostMapping
@ResponseStatus(HttpStatus.CREATED)
public PersonRequest add(@Valid @RequestBody PersonRequest person) { return person; }

Client nhìn thấy gì

Trong Spring MVC, "các lỗi validation được báo dưới dạng MethodArgumentNotValidException", và thường dẫn tới HTTP 400 Bad Request. Validation ở cấp method dùng @Validated trên class.[1]

RESULT POST valid body -> 201 Created
RESULT POST invalid body (blank name, age -1) -> 400 Bad Request

Code: PersonRequest.java, PersonController.java, PersonControllerTest.java. Nội dung body của response 400 và các định dạng lỗi tuỳ biến nằm ngoài các trang đã đọc; tài liệu về error response của MVC được link ở trên có đề cập.

Hãy validate ở tầng biên (controller) và cả trong database bằng constraint: database là tuyến phòng thủ cuối cùng.

Đã kiểm chứng: project trong examples/demo-app (Spring Boot 4.1.1, JDK 21, tạo bằng Spring Initializr) đã được build và chạy test trong một Maven container; các dòng đánh dấu RESULT lấy từ chính những test đó. Tự chạy thử: cd spring-boot/examples/demo-app && ./mvnw test (hoặc dùng image maven:3-eclipse-temurin-21).

Luyện truy hồi

Trả lời theo trí nhớ. Mỗi câu chỉ một lần chọn.

1. Annotation nào kích hoạt validation cho body?

@Valid trên tham số bật validation.[1]

2. Exception khi validate thất bại trong Spring MVC?

Lỗi validation được báo dưới dạng MethodArgumentNotValidException.[1]

3. Status thường gặp cho input không hợp lệ?

Thường nó dẫn tới HTTP 400 (test trả về 400).[1]

4. Constraint nào cấm null?

@NotNull là một constraint annotation có sẵn.[1]
