@ConfigurationProperties: cấu hình type-safe

Spring Boot · Bài 0009 · bước 6/13 · Core · ~10 phút · Trang chủ · Lộ trình Spring Boot · Lộ trình tổng · English

Thành quả hôm nay: bind một nhóm property vào một object bất biến có kiểu rõ ràng, kèm giá trị mặc định và validation.

Vì sao không dùng @Value

@ConfigurationProperties cung cấp cơ chế bind type-safe từ cấu hình bên ngoài vào các bean có kiểu chặt chẽ, và hợp với các property phân cấp hoặc phức tạp hơn là rải @Value khắp nơi.[1]

Một record bất biến

@ConfigurationProperties("app")
@Validated
public record AppProperties(@NotBlank String name, @DefaultValue("hello") String greeting) { }

@SpringBootApplication
@EnableConfigurationProperties(AppProperties.class)
class DemoApplication { ... }
  • Constructor binding cho bạn bean bất biến và dùng được với record; @DefaultValue cung cấp giá trị mặc định.[1]
  • Relaxed binding: my-project, myProject và env var MY_PROJECT đều bind vào cùng một property.[1]
  • Validation: thêm @Validated và các constraint annotation; thiếu một giá trị bắt buộc thì app khởi động thất bại.[1]
  • Bật bằng @EnableConfigurationProperties hoặc @ConfigurationPropertiesScan.[1]

Đã kiểm chứng: app.name=demo-app và greeting mặc định được bind thành name=demo-app greeting=hello (dòng RESULT ở bài trước). Code: AppProperties.java. Tôi chưa chạy trường hợp lỗi "thiếu giá trị bắt buộc"; tài liệu nêu đó là một lợi ích của @Validated.

Đã kiểm chứng: project trong examples/demo-app (Spring Boot 4.1.1, JDK 21, tạo bằng Spring Initializr) đã được build và chạy test trong một Maven container; các dòng đánh dấu RESULT lấy từ chính những test đó. Tự chạy thử: cd spring-boot/examples/demo-app && ./mvnw test (hoặc dùng image maven:3-eclipse-temurin-21).

Luyện truy hồi

Trả lời theo trí nhớ. Mỗi câu chỉ một lần chọn.

1. Cấu hình theo nhóm, type-safe thì dùng...?

Nó bind cấu hình bên ngoài vào các bean có kiểu chặt chẽ.[1]

2. Làm sao có được một object properties bất biến?

Constructor binding dùng được cho bean bất biến và record.[1]

3. Env var MY_SERVICE_PORT bind vào property nào?

Relaxed binding ánh xạ dấu gạch dưới trong env var thành tên property.[1]

4. Cái gì làm cho một properties class được validate?

@Validated bật validation JSR-303 cho các giá trị đã bind.[1]
