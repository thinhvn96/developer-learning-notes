Testing: @SpringBootTest và test slice

Spring Boot · Bài 0012 · bước 12/13 · Advanced · ~12 phút · Trang chủ · Lộ trình Spring Boot · Lộ trình tổng · English

Thành quả hôm nay: chọn giữa một @SpringBootTest đầy đủ và một test slice, và biết webEnvironment làm gì.

@SpringBootTest

Nó tạo ApplicationContext thông qua SpringApplication, nên external properties, logging và profile đều hoạt động. Mặc định nó không khởi động server. webEnvironment: MOCK (mặc định, môi trường servlet giả lập), RANDOM_PORT và DEFINED_PORT (embedded server thật), NONE (không có môi trường web).[1]

Slice

Slice chỉ load một phần cấu hình để chạy nhanh hơn và tập trung vào một tầng: @WebMvcTest (controller, advice, filter, converter), @DataJpaTest (các component JPA), @JsonTest, @RestClientTest. Thay bean bằng @MockitoBean/@MockitoSpyBean. Test bằng MockMvc nhanh hơn chạy server thật nhưng không test được hành vi của servlet container.[1]

@WebMvcTest(PersonController.class)     // only the web layer
class PersonControllerTest { @Autowired MockMvc mvc; ... }

@SpringBootTest @AutoConfigureMockMvc   // full context + MockMvc
class ActuatorProbesTest { ... }

Cả hai kiểu đều đã chạy trong demo project (17 test, tất cả đều pass). Lưu ý với Boot 4.x: các annotation slice nằm trong package riêng theo từng công nghệ, ví dụ org.springframework.boot.webmvc.test.autoconfigure.WebMvcTest (tôi vấp phải lỗi này khi compile; hãy kiểm tra import nếu copy các ví dụ cũ). Code: PersonControllerTest.java.

Quy tắc kinh nghiệm khi phỏng vấn: nhiều slice test chạy nhanh, ít test full-context, và integration test với dependency thật cho tầng persistence (xem Testcontainers ở bài tiếp theo).

Đã kiểm chứng: project trong examples/demo-app (Spring Boot 4.1.1, JDK 21, tạo bằng Spring Initializr) đã được build và chạy test trong một Maven container; các dòng đánh dấu RESULT lấy từ chính những test đó. Tự chạy thử: cd spring-boot/examples/demo-app && ./mvnw test (hoặc dùng image maven:3-eclipse-temurin-21).

Luyện truy hồi

Trả lời theo trí nhớ. Mỗi câu chỉ một lần chọn.

1. webEnvironment mặc định của @SpringBootTest?

MOCK là mặc định; không có server nào được khởi động.[1]

2. Annotation nào chỉ test controller?

@WebMvcTest scan controller và các component web.[1]

3. Vì sao nên ưu tiên slice?

Slice chỉ load cấu hình liên quan, giúp giảm thời gian khởi động.[1]

4. Annotation để thay một bean bằng mock?

@MockitoBean định nghĩa các Mockito mock trong context.[1]
