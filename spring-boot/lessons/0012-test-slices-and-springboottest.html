Testing: @SpringBootTest and test slices

Spring Boot · Lesson 0012 · step 12 of 13 · Advanced · ~12 minutes · Home · Spring Boot ladder · Roadmap

Today's win: choose between a full @SpringBootTest and a test slice, and know what webEnvironment does.

@SpringBootTest

Creates the ApplicationContext through SpringApplication, so external properties, logging and profiles work. It does not start a server by default. webEnvironment: MOCK (default, mock servlet environment), RANDOM_PORT and DEFINED_PORT (real embedded server), NONE (no web environment).[1]

Slices

Slices load only part of the configuration to run faster and focus on one layer: @WebMvcTest (controllers, advice, filters, converters), @DataJpaTest (JPA components), @JsonTest, @RestClientTest. Replace beans with @MockitoBean/@MockitoSpyBean. MockMvc tests are faster than a running server but cannot test servlet-container behavior.[1]

@WebMvcTest(PersonController.class)     // only the web layer
class PersonControllerTest { @Autowired MockMvc mvc; ... }

@SpringBootTest @AutoConfigureMockMvc   // full context + MockMvc
class ActuatorProbesTest { ... }

Both styles ran in the demo project (17 tests, all passing). Note for Boot 4.x: the slice annotations live in per-technology packages, for example org.springframework.boot.webmvc.test.autoconfigure.WebMvcTest (I hit this when compiling; check imports if copying older examples). Code: PersonControllerTest.java.

Rule of thumb for interviews: many fast slice tests, few full-context tests, and real-dependency integration tests for persistence (see Testcontainers next).

Verified: the project in examples/demo-app (Spring Boot 4.1.1, JDK 21, generated with Spring Initializr) was built and its tests run in a Maven container; lines marked RESULT come from those tests. Run them yourself: cd spring-boot/examples/demo-app && ./mvnw test (or use the maven:3-eclipse-temurin-21 image).

Retrieval practice

Answer from memory. One attempt each.

1. Default webEnvironment for @SpringBootTest?

MOCK is the default; no server starts.[1]

2. Which annotation tests only controllers?

@WebMvcTest scans controllers and web components.[1]

3. Why prefer slices?

Slices load only relevant configuration, reducing startup time.[1]

4. Annotation to replace a bean with a mock?

@MockitoBean defines Mockito mocks in the context.[1]
