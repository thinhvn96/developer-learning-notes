Constructor injection so với setter injection

Spring Boot · Bài 0002 · bước 2/13 · Foundation · ~10 phút · Trang chủ · Lộ trình Spring Boot · Lộ trình tổng · English

Thành quả hôm nay: lập luận cho việc dùng constructor injection với các dependency bắt buộc, dựa trên chính lý do của đội Spring.

Hai biến thể

DI dựa trên constructor: container gọi một constructor có tham số chính là các dependency. DI dựa trên setter: container gọi các setter sau khi gọi constructor không tham số.[1]

Khuyến nghị

"Dùng constructor cho các dependency bắt buộc, và setter method hoặc configuration method cho các dependency tuỳ chọn." Đội Spring nhìn chung ủng hộ constructor injection vì nó cho phép bạn xây dựng component dưới dạng object bất biến (immutable), đảm bảo các dependency bắt buộc không bị null, và trả về component ở trạng thái đã khởi tạo đầy đủ.[1]

@Service
public class OrderService {
    private final PaymentGateway payments;
    public OrderService(PaymentGateway payments) { this.payments = payments; }
}

File: OrderService.java. Setter injection dành cho các dependency tuỳ chọn có giá trị mặc định hợp lý, hoặc các class bên thứ ba mà bạn không ràng buộc được.[1]

Dependency vòng tròn

Chúng có thể xảy ra với constructor injection và gây ra BeanCurrentlyInCreationException; dùng setter injection cho một trong các bean có thể gỡ được vòng này.[1] Nhưng tốt hơn là thiết kế lại để bỏ hẳn vòng tròn.

Đã kiểm chứng: project trong examples/demo-app (Spring Boot 4.1.1, JDK 21, tạo bằng Spring Initializr) đã được build và chạy test trong một Maven container; các dòng đánh dấu RESULT lấy từ chính những test đó. Tự chạy thử: cd spring-boot/examples/demo-app && ./mvnw test (hoặc dùng image maven:3-eclipse-temurin-21).

Luyện truy hồi

Trả lời theo trí nhớ. Mỗi câu chỉ một lần chọn.

1. Kiểu injection nào được khuyên dùng cho dependency bắt buộc?

Dùng constructor cho các dependency bắt buộc.[1]

2. Constructor injection cho phép bạn làm gì?

Nó cho phép bạn hiện thực component dưới dạng object bất biến.[1]

3. Dependency vòng tròn qua constructor gây ra gì?

Dependency vòng tròn với constructor injection sẽ ném BeanCurrentlyInCreationException.[1]

4. Setter injection hợp với trường hợp nào?

Setter dành cho các dependency tuỳ chọn có thể có giá trị mặc định hợp lý.[1]
