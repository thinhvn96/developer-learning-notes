REST controller và request mapping

Spring Boot · Bài 0004 · bước 7/13 · Core · ~10 phút · Trang chủ · Lộ trình Spring Boot · Lộ trình tổng · English

Thành quả hôm nay: viết một REST controller có path variable và mapping HTTP method đúng, và giải thích vì sao các composed annotation được ưu tiên dùng.

Các annotation mapping viết tắt

Spring MVC ánh xạ request tới các method của controller bằng @RequestMapping, và cung cấp các composed annotation @GetMapping, @PostMapping, @PutMapping, @DeleteMapping và @PatchMapping. Chúng được ưu tiên vì phần lớn method của controller nên ánh xạ tới một HTTP method cụ thể, trong khi @RequestMapping đứng một mình thì "mặc định khớp với mọi HTTP method".[1]

@RestController
@RequestMapping("/persons")
class PersonController {

    @GetMapping("/{id}")
    public Person getPerson(@PathVariable Long id) { ... }

    @PostMapping
    @ResponseStatus(HttpStatus.CREATED)
    public void add(@RequestBody Person person) { ... }
}

File: PersonController.java. @PathVariable bind đoạn {id}; @RequestBody bind body của request vào một object; @ResponseStatus(HttpStatus.CREATED) trả về 201.[1]

Góc phỏng vấn: "PUT khác PATCH thế nào, và cái nào idempotent?" là câu hỏi về ngữ nghĩa HTTP, không phải về Spring. Hãy liên hệ với bài về retry: retry cần các thao tác idempotent.

Đã kiểm chứng: project trong examples/demo-app (Spring Boot 4.1.1, JDK 21, tạo bằng Spring Initializr) đã được build và chạy test trong một Maven container; các dòng đánh dấu RESULT lấy từ chính những test đó. Tự chạy thử: cd spring-boot/examples/demo-app && ./mvnw test (hoặc dùng image maven:3-eclipse-temurin-21).

Luyện truy hồi

Trả lời theo trí nhớ. Mỗi câu chỉ một lần chọn.

1. Annotation nào chỉ ánh xạ HTTP GET?

@GetMapping là composed annotation dành cho GET.[1]

2. @RequestMapping đứng một mình khớp với method nào?

Mặc định nó khớp với mọi HTTP method.[1]

3. Cái nào bind đoạn URL {id}?

@PathVariable bind một biến trong URI template.[1]

4. Cái nào đặt response 201 cho POST?

@ResponseStatus(HttpStatus.CREATED) đặt status.[1]
