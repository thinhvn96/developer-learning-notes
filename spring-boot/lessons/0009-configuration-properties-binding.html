@ConfigurationProperties: type-safe configuration

Spring Boot · Lesson 0009 · step 6 of 13 · Core · ~10 minutes · Home · Spring Boot ladder · Roadmap

Today's win: bind a group of properties to an immutable typed object with defaults and validation.

Why not @Value

@ConfigurationProperties provides type-safe binding of externalized configuration to strongly typed beans, and suits hierarchical or complex properties better than scattered @Value injection.[1]

An immutable record

@ConfigurationProperties("app")
@Validated
public record AppProperties(@NotBlank String name, @DefaultValue("hello") String greeting) { }

@SpringBootApplication
@EnableConfigurationProperties(AppProperties.class)
class DemoApplication { ... }
  • Constructor binding gives immutable beans and works with records; @DefaultValue supplies defaults.[1]
  • Relaxed binding: my-project, myProject and env var MY_PROJECT all bind to the same property.[1]
  • Validation: add @Validated and constraint annotations; a missing required value fails startup.[1]
  • Enable with @EnableConfigurationProperties or @ConfigurationPropertiesScan.[1]

Verified: app.name=demo-app and the default greeting bound as name=demo-app greeting=hello (RESULT line in the previous lesson). Code: AppProperties.java. I did not run the "missing required value" failure case; the docs state it as a benefit of @Validated.

Verified: the project in examples/demo-app (Spring Boot 4.1.1, JDK 21, generated with Spring Initializr) was built and its tests run in a Maven container; lines marked RESULT come from those tests. Run them yourself: cd spring-boot/examples/demo-app && ./mvnw test (or use the maven:3-eclipse-temurin-21 image).

Retrieval practice

Answer from memory. One attempt each.

1. Type-safe grouped config uses...?

It binds externalized configuration to strongly typed beans.[1]

2. How do you get an immutable properties object?

Constructor binding works for immutable beans and records.[1]

3. Env var MY_SERVICE_PORT binds to which property?

Relaxed binding maps underscores in env vars to property names.[1]

4. What makes a properties class validate?

@Validated enables JSR-303 validation of the bound values.[1]
