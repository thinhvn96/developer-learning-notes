# Bài tập 0003: đọc conditions report

Đi kèm [bài 3](../lessons/0003-auto-configuration.vi.html) · [English](0003-read-the-conditions-report.md)

Tạo một project Spring Boot với starter Web và JDBC (nếu cần, hãy hỏi giáo viên các bước). Chạy với `--debug`. Tìm một positive match và một negative match trong conditions report. Sau đó thêm bean `DataSource` của riêng bạn và xem điều gì thay đổi.
