# Exercise 0001: explain IoC

Companion to [lesson 1](../lessons/0001-ioc-and-beans.html).

Explain IoC, DI, bean and ApplicationContext in 90 seconds as if to an interviewer. Then write a plain-Java `main` that builds `OrderService` and its dependency by hand. What changes when a container does this for you, and what does that buy you in a unit test?
