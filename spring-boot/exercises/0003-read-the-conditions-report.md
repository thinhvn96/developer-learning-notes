# Exercise 0003: read the conditions report

[Tiếng Việt](0003-read-the-conditions-report.vi.md)

Companion to [lesson 3](../lessons/0003-auto-configuration.html).

Generate a Spring Boot project with the Web and JDBC starters (ask your teacher for the steps if needed). Run with `--debug`. Find one positive match and one negative match in the conditions report. Then add your own `DataSource` bean and see what changes.
