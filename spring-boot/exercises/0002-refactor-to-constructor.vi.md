# Bài tập 0002: refactor sang constructor injection

Đi kèm [bài 2](../lessons/0002-constructor-injection.vi.html) · [English](0002-refactor-to-constructor.md)

Lấy một class có ba field `@Autowired` và refactor sang constructor injection với các field `final`. Liệt kê những gì bạn thu được (tính bất biến, an toàn với null, dễ test) và một class có tám tham số constructor đang nói với bạn điều gì.
