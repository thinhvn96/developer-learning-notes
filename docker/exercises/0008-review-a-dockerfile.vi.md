# Bài tập 0008

Đi kèm [bài 8](../lessons/0008-dockerfile-instructions.vi.html) · [English](0008-review-a-dockerfile.md)

Tìm ba vấn đề trong Dockerfile sau: `FROM ubuntu` / `ADD app.jar /app.jar` / `ENV DB_PASSWORD=secret` / `RUN apt-get update` / `CMD java -jar /app.jar`. Sửa chúng (COPY vs ADD, cách xử lý secret, layer, exec form).
