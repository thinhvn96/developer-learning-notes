docker run: các flag và vòng đời của container

Docker · Bài 0007 · bước 2/12 · Foundation · ~10 phút · Trang chủ · Lộ trình Docker · Lộ trình tổng · English

Thành quả hôm nay: start, đặt tên, publish port, stop và xóa một container, và nói được flag nào làm gì.

docker run

docker run sẽ "tạo và chạy một container mới từ một image", tự pull image nếu cần.[1] Các flag bạn dùng hằng ngày:

FlagÝ nghĩa[1]
-dchạy như một process nền, không chiếm terminal của bạn
-p host:containerpublish một port của container ra host, ví dụ -p 127.0.0.1:80:8080/tcp
--rmtự động xóa container (cùng các anonymous volume của nó) khi thoát
-e VAR=valueđặt một biến môi trường; --env-file nạp từ một file
--nameđặt tên cho container thay vì để tên ngẫu nhiên
-itgiữ STDIN mở và cấp một pseudo-TTY cho phiên tương tác

Vòng đời trong một lần chạy

cd docker/examples && ./02-run-and-lifecycle.sh
GREETING=hello
GET / -> HTTP 200
running:  lesson-web-... Up 1 second
stopped:  lesson-web-... Exited (0) Less than a second ago
after rm, containers named that: 0

Container đã stop vẫn còn tồn tại (cả writable layer của nó) cho tới khi bạn docker rm. Source: 02-run-and-lifecycle.sh.

Luyện truy hồi

Trả lời theo trí nhớ. Mỗi câu chỉ một lần chọn.

1. Flag nào chạy container ở chế độ nền?

-d start container như một process nền.[1]

2. --rm làm gì?

Nó tự động xóa container và các anonymous volume của container khi container thoát.[1]

3. Flag nào publish port?

-p publish một port của container ra host.[1]

4. Một container đã stop thì vẫn...?

Bản demo cho thấy nó vẫn được liệt kê với trạng thái Exited cho tới khi docker rm.
