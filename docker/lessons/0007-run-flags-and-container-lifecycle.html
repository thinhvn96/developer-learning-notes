docker run: flags and the container lifecycle

Docker · Lesson 0007 · step 2 of 12 · Foundation · ~10 minutes · Home · Docker ladder · Roadmap

Today's win: start, name, publish, stop and remove a container, and say which flag does what.

docker run

docker run will "create and run a new container from an image", pulling the image if needed.[1] The flags you use daily:

FlagMeaning[1]
-drun as a background process that does not occupy your terminal
-p host:containerpublish a container port to the host, e.g. -p 127.0.0.1:80:8080/tcp
--rmautomatically remove the container (and its anonymous volumes) on exit
-e VAR=valueset an environment variable; --env-file loads a file
--namegive the container a name instead of a random one
-itkeep STDIN open and allocate a pseudo-TTY for an interactive session

A stopped container still exists (its writable layer too) until you docker rm it. Source: 02-run-and-lifecycle.sh.

Retrieval practice

Answer from memory. One attempt each.

1. Which flag runs a container in the background?

-d starts a container as a background process.[1]

2. What does --rm do?

It automatically removes the container and its anonymous volumes when it exits.[1]

3. Which flag publishes a port?

-p publishes a container port to the host.[1]

4. A stopped container still...?

The demo showed it listed as Exited until docker rm.
