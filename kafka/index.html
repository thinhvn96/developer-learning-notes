Kafka: simple to advanced

Home · Stack index · Interview Q&A · Roadmap · Cheat sheet · 23 lessons · Tiếng Việt

From "what is a topic" to KRaft, share groups and multi-region design, in 23 short lessons and reading order. Every lesson cites the Apache Kafka 4.3 docs (or Spring / Confluent docs where noted) and most have a script that runs against a throwaway apache/kafka:4.3.1 container. Tick lessons off as you go (saved in this browser only). Folders: lessons/, exercises/, examples/.
