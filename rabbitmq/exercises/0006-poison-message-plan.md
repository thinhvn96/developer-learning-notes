# Exercise 0006: a poison message plan

Companion to [lesson 6](../lessons/0006-quorum-queues-and-poison-messages.html). · [Tiếng Việt](0006-poison-message-plan.vi.md)

A consumer throws on messages with a malformed field. Write the end-to-end plan: queue type, delivery limit, DLX, what is stored with the dead letter, an alert, and a replay procedure after a fix. Why must the consumer itself still be idempotent?
