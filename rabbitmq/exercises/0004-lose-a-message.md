# Exercise 0004: find every way to lose a message

Companion to [lesson 4](../lessons/0004-publisher-confirms-and-durability.html). · [Tiếng Việt](0004-lose-a-message.vi.md)

List at least five ways a message can be lost between publisher and consumer (unroutable, non-durable queue, transient message, auto-ack, no publisher confirms, broker crash before persistence...). Next to each, write the setting or practice that closes the gap.
