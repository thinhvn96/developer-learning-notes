# Exercise 0006: probe design

[Tiếng Việt](0006-probe-design.vi.md)

Companion to [lesson 6](../lessons/0006-probes.html).

A Spring Boot service takes 45 s to start, calls a database and a payment API. Design startup, readiness and liveness probes: path, period, failure threshold. For each, say what should and should not be checked, and what happens if the payment API is down.
