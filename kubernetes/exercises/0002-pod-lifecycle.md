# Exercise 0002: Pod lifecycle

Companion to [lesson 2](../lessons/0002-pods.html).

On a local cluster (kind or minikube; check their docs to install), apply `examples/pod.yaml`, then `kubectl delete pod nginx`. What recreates it? Repeat with `examples/deployment.yaml` and delete one Pod. What differs, and which component explains it?

If you have no cluster yet, answer from the docs instead and note the gap for the teacher.
