PersistentVolumes, claims and StorageClasses

Kubernetes · Lesson 0012 · step 12 of 15 · Advanced · ~10 minutes · Home · Kubernetes ladder · Roadmap · Tiếng Việt

Today's win: distinguish PersistentVolume, PersistentVolumeClaim and StorageClass, and show data outliving a Pod.

Three objects

  • PersistentVolume (PV): a piece of storage provisioned by an admin or dynamically, a cluster resource with a lifecycle independent of any Pod.
  • PersistentVolumeClaim (PVC): a user's request for storage (size, access mode), a "claim check" to a PV.
  • StorageClass: lets admins offer different kinds of storage without exposing implementation details.[1]

Dynamic provisioning creates a PV automatically when a PVC names a StorageClass that is set up for it.[1]

Access modes and reclaim

ReadWriteOnce (one node), ReadOnlyMany, ReadWriteMany, ReadWriteOncePod (one Pod). Reclaim policy when the claim is deleted: Retain (manual), Delete (PV removed); Recycle is deprecated.[1]

kubectl apply -f examples/pvc-pod.yaml
data-claim  Bound  pvc-2582...  100Mi  RWO  standard        # dynamically provisioned
writer  logs: persisted-1790275692
# delete the Pod, start another one on the same claim:
writer2 logs: persisted-1790275692
              persisted-1790275698          # earlier data still there

File: pvc-pod.yaml. Compare Docker volumes (lesson). Deleting the Pod did not delete the claim; whether the data survives claim deletion depends on the reclaim policy.[1]

Verified: I applied the manifests in examples/ to a throwaway kind cluster (Kubernetes v1.37.0, kubectl v1.37.1) and quote outputs from that run. The kind setup itself is not covered by the pages I read; follow the project's own docs.

Retrieval practice

Answer from memory. One attempt each.

1. A PVC is...?

A PersistentVolumeClaim is a user's request for storage.[1]

2. Which object describes classes of storage?

StorageClass offers varying PVs without exposing implementation details.[1]

3. ReadWriteOnce means...?

ReadWriteOnce mounts read-write by a single node.[1]

4. Reclaim policy Retain means...?

Retain requires manual reclamation.[1]
