StatefulSets: stable identity and storage

Kubernetes · Lesson 0013 · step 13 of 15 · Advanced · ~12 minutes · Home · Kubernetes ladder · Roadmap

Today's win: explain what a StatefulSet guarantees that a Deployment does not, and prove stable identity and storage on a cluster.

Guarantees

A StatefulSet "manages the deployment and scaling of a set of Pods, and provides guarantees about the ordering and uniqueness of these Pods": stable unique network identifiers, stable persistent storage, ordered graceful deployment and scaling, ordered rolling updates.[1] For stateless apps use a Deployment.[1]

Requirements and limits

  • A headless Service (clusterIP: None) must be created by you to own the Pods' network identity.[1]
  • "Deleting and/or scaling a StatefulSet down will not delete the volumes" - data safety over automatic purge.[1]
  • No guarantee of ordered termination on delete; scale to 0 first for an ordered shutdown.[1]

Verified on a cluster

kubectl apply -f examples/statefulset.yaml      # 2 replicas + volumeClaimTemplates
web-0  1/1 Running  19s          web-1  1/1 Running  4s         # created in order
data-web-0  Bound ...            data-web-1  Bound ...         # one PVC per Pod
kubectl exec web-0 -- sh -c 'echo "page from web-0" > /usr/share/nginx/html/index.html'
kubectl delete pod web-0     # recreated with the SAME name and a new uid
kubectl exec web-0 -- cat /usr/share/nginx/html/index.html   -> page from web-0
web-0.web.default.svc.cluster.local resolves to the Pod IP
kubectl scale statefulset web --replicas=1   -> data-web-1 still exists

File: statefulset.yaml. Interview line: StatefulSets give identity and storage, not data replication; a database still needs its own replication (my inference, consistent with the guarantees above).

Verified: I applied the manifests in examples/ to a throwaway kind cluster (Kubernetes v1.37.0, kubectl v1.37.1) and quote outputs from that run. The kind setup itself is not covered by the pages I read; follow the project's own docs.

Retrieval practice

Answer from memory. One attempt each.

1. What must exist for a StatefulSet's network identity?

StatefulSets require a headless Service that you create.[1]

2. Scale a StatefulSet down. Volumes?

Scaling down does not delete the volumes.[1]

3. Pods are created in what manner?

Deployment and scaling are ordered.[1]

4. Pod web-0 is deleted. What comes back?

The run showed web-0 recreated with its data intact.
