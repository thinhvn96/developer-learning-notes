Horizontal Pod Autoscaler

Kubernetes · Lesson 0015 · step 15 of 15 · Senior · ~12 minutes · Home · Kubernetes ladder · Roadmap

Today's win: compute the desired replica count from the HPA formula and state the prerequisites for it to work.

What it does

The HorizontalPodAutoscaler updates a workload (Deployment, StatefulSet) to match demand by adding or removing Pods; it does not apply to objects that cannot be scaled, such as DaemonSets.[1]

The algorithm:

desiredReplicas = ceil[ currentReplicas x ( currentMetricValue / desiredMetricValue ) ]

Example from the docs: a current value of 200m against a target of 100m doubles the replica count.[1] The controller re-evaluates every 15 seconds by default.[1] Worked example: 3 Pods at 90 percent average CPU with a 70 percent target gives ceil(3 x 90/70) = ceil(3.86) = 4 Pods (my arithmetic with the documented formula).

Prerequisites

  • For utilization targets, containers must define resource requests; otherwise CPU utilization is undefined and the autoscaler takes no action for that metric.[1]
  • A metrics source, typically the Metrics Server add-on, launched separately.[1]
kubectl apply -f examples/hpa.yaml
NAME        REFERENCE                     TARGETS              MINPODS MAXPODS REPLICAS
nginx-hpa   Deployment/nginx-deployment   cpu: <unknown>/70%   2       6       3

<unknown> is what you see with no metrics server (and no requests on the nginx Deployment): the HPA exists but cannot act. Connect to the requests lesson: without requests there is nothing to compute utilization against. File: hpa.yaml.

Retrieval practice

Answer from memory. One attempt each.

1. Formula uses which ratio?

desired = ceil(current replicas x current metric / desired metric).[1]

2. Utilization targets need what on containers?

Without requests the CPU utilization is undefined.[1]

3. Where does HPA get resource metrics?

It typically needs the metrics API from a Metrics Server add-on.[1]

4. Which workload can HPA not scale?

HPA does not apply to objects that cannot be scaled, like DaemonSets.[1]
