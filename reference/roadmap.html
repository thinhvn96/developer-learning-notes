Suggested order

Within each stack the lessons run simple to advanced, in the order shown. Across stacks: Java first, then OOP and Design Patterns (with Docker alongside), PostgreSQL and Spring Boot next, then the messaging and search stacks (Kafka, RabbitMQ, ELK), then Kubernetes (which reuses Docker and JVM memory ideas), then system design, which combines everything. Inside each stack the lessons are already in reading order, simple to advanced. Each stack also has an interview Q&A page you can start using at any time. Tell your teacher if you want a different order.

How the phases interleave

RhythmWhat happens
Each sessionOne new lesson, plus 2-3 review questions from earlier lessons (spacing).
Every 4th sessionMixed quiz across stacks, or a mock interview from any interview Q&A page (interleaving).
Phases 2 and 3May run in parallel with Phase 1 if you prefer variety.
