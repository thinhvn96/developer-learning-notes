HashMap numbers

Capacity 16 (power of two) · load factor 0.75 → resize at 12, doubles · hash = h ^ (h >>> 16) · index = (n − 1) & hash · bin → tree at 8 nodes if table ≥ 64, back at 6 · one null key allowed · presize: HashMap.newHashMap(n) (JDK 19+) or new HashMap<>((int)(n / 0.75f) + 1). Traps

  • list.remove(x) inside for-each → ConcurrentModificationException (or a silent skip). Use removeIf / Iterator.remove.
  • Comparator by one field in a TreeSet/TreeMap drops "duplicates". Add a tie-breaker.
  • (a, b) -> a - b overflows. Use Integer.compare / Comparator.comparingInt.
  • unmodifiableList is a view; List.copyOf is a copy; neither freezes mutable elements.
  • Integer == works only for -128..127 constants. Use equals.
  • List<Integer>.remove(1) removes index 1.
  • putIfAbsent(k, expensive()) always runs expensive(). Use computeIfAbsent.
  • Do not modify a map inside its own compute* function (HashMap may throw CME).
  • Printing a PriorityQueue or HashSet shows no meaningful order.
  • Iterating a synchronizedList needs synchronized (list) { ... }.
