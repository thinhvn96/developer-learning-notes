# Exercise 0002: map an access log

Companion to [lesson 2](../lessons/0002-documents-indices-and-mappings.html). · [Tiếng Việt](0002-map-an-access-log.vi.md)

Write an explicit mapping for access logs (`@timestamp`, `client_ip`, `method`, `path`, `status`, `duration_ms`, `user_agent`). For each field pick a type and say why. Which fields are `keyword` and which `text`? Run it in the throwaway Elasticsearch.
