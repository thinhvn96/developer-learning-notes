# Bài tập 0001: vẽ pipeline

Bài tập đi kèm [bài 1](../lessons/0001-elk-overview-and-pipeline.vi.html). · [English](0001-draw-the-pipeline.md)

Vẽ đường đi của một dòng log từ file log của một Java service tới một query trên Kibana. Ghi tên từng thành phần, nói rõ nó lưu hoặc buffer cái gì, và đánh dấu chỗ bạn sẽ đặt Kafka nếu log phải sống sót qua một lần Elasticsearch sập. Những thành phần nào cung cấp giao nhận at-least-once?
