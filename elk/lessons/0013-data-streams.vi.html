Data stream và rollover

ELK Stack · Bài 0013 · bước 13/14 · Advanced · ~12 phút · Trang chủ · Lộ trình ELK Stack · Lộ trình tổng · English

Thành quả hôm nay: giải thích được data stream là gì, vì sao nó cần @timestamp, rollover làm gì, và khi nào nên dùng alias thay thế.

Data stream là gì

Data stream là "một lớp trừu tượng nằm trên một tập index được tối ưu để lưu dữ liệu time series chỉ ghi thêm (append-only)": bạn chỉ dùng một cái tên, còn nó tự quản lý các backing index ẩn, được sinh tự động. Mọi document đều cần field @timestamp (kiểu date hoặc date_nanos). Backing index mới nhất là write index; một lần rollover sẽ tạo backing index mới, tự động qua ILM hoặc thủ công.[1]

Không dành cho: những workload liên tục gửi document với cùng một _id và mong bản ghi sau cùng thắng (last-write-wins); trường hợp đó hãy dùng index alias có write index.[1]

PUT _index_template/logs-app {"index_patterns":["logs-app*"],"data_stream":{}}
POST logs-app/_doc {"@timestamp":"...","message":"first"}
  -> indexed into backing index .ds-logs-app-2026.09.24-000001
POST logs-app/_doc {"message":"no timestamp"}
  -> failed to parse: data stream timestamp field [@timestamp] is missing
POST logs-app/_rollover
  -> rolled_over true; new index .ds-logs-app-2026.09.24-000002
GET _data_stream/logs-app -> backing indices: [...-000001, ...-000002]

Log và metric là những thứ hợp tự nhiên nhất; Filebeat và Logstash có thể ghi vào data stream (mình chưa test chuyện đó ở đây). Script: 04-ingest-datastream-ilm.sh. Tiếp theo: tự động hoá rollover và xoá dữ liệu bằng ILM.

Luyện truy hồi

Trả lời theo trí nhớ. Mỗi câu chỉ một lần chọn.

1. Mọi document trong data stream bắt buộc có field nào?

Document phải có @timestamp; lần chạy đã từ chối một document thiếu field này.[1]

2. Write index là gì?

Backing index gần nhất đóng vai trò write index.[1]

3. Rollover làm gì?

Rollover tạo một backing index mới và index đó trở thành write index.[1]

4. Trường hợp nào không hợp với data stream?

Workload kiểu cùng _id, bản ghi sau thắng nên dùng alias thay thế.[1]
