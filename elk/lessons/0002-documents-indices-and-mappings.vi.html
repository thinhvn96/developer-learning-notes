Document, index và mapping

ELK Stack · Bài 0002 · bước 3/14 · Foundation · ~10 phút · Trang chủ · Lộ trình ELK Stack · Lộ trình tổng · English

Thành quả hôm nay: giải thích được index, document và mapping, và vì sao trên production bạn chọn explicit mapping.

Định nghĩa

Theo tài liệu, "index là đơn vị lưu trữ cơ bản trong Elasticsearch, và là tầng mà bạn tương tác với dữ liệu của mình." Một index gồm các document (object JSON với các field dạng key-value), mapping (kiểu dữ liệu của field và cách field được đánh index, được query), và settings (shard, replica, refresh interval).[1]

Tài liệu khuyên dùng dynamic mapping khi khám phá dữ liệu và explicit mapping cho production, đồng thời dùng alias để tách query khỏi tên index.[1]

Một explicit mapping

PUT /logs
{ "mappings": { "properties": {
    "message": { "type": "text" },       // analyzed: full-text search
    "level":   { "type": "keyword" },    // exact value: filters and aggregations
    "service": { "type": "keyword" } } } }

Chọn text hay keyword chính là quyết định khiến query của bạn chạy đúng hay không, như bài 5 sẽ cho thấy. Script: 01-elasticsearch-basics.sh.

Câu hỏi phỏng vấn: "Nếu tôi để dynamic mapping tự đoán thì sao?" Nó suy ra kiểu từ document đầu tiên nó thấy, mà kiểu đó có thể không hợp với query của bạn; mapping của các field đã tồn tại thì không thể đơn giản là sửa, nên hãy lên kế hoạch từ đầu (cách reindex nằm ngoài các đoạn trích đã đọc ở đây; hãy hỏi giáo viên).

Luyện truy hồi

Trả lời theo trí nhớ. Mỗi câu chỉ một lần chọn.

1. Mapping định nghĩa điều gì?

Mapping xác định kiểu dữ liệu của field và điều khiển cách đánh index, cách query.[1]

2. Document trong Elasticsearch là gì?

Document là object JSON chứa các field dạng key-value.[1]

3. Production nên dùng dynamic hay explicit mapping?

Dùng dynamic mapping khi khám phá, explicit mapping cho production.[1]

4. Phần nào của index chứa refresh interval?

Settings điều khiển shard, replica và refresh interval.[1]
