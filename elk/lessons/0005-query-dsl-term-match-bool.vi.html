Query DSL: term, match và bool

ELK Stack · Bài 0005 · bước 7/14 · Core · ~10 phút · Trang chủ · Lộ trình ELK Stack · Lộ trình tổng · English

Thành quả hôm nay: chọn đúng giữa match và term, và dựng một bool query dùng filter cho các điều kiện chính xác.

text và keyword, term và match

"Tránh dùng term query cho các field text." Mặc định Elasticsearch biến đổi giá trị text trong quá trình analysis, điều này "có thể khiến việc tìm khớp chính xác giá trị của field text trở nên khó khăn"; hãy dùng match cho field text.[1] Các giá trị chính xác như id hay username thì nên nằm trong field keyword, và search bằng term.

term  'Timeout' (exact token):            0 hits
term  'timeout' (lowercased token):       1 hit
match 'Timeout' (query is analyzed too):  1 hit

Message Connection Timeout to payment-service đã được analyze thành các token viết thường, nên term với Timeout trượt còn match thì tìm ra (kết quả từ script).

bool

  • must và should góp vào điểm relevance (relevance score).
  • filter và must_not chạy trong filter context: bỏ qua việc tính điểm và được cache.[2]
{ "query": { "bool": {
    "filter": [ { "term":  { "level": "ERROR" } } ],
    "must":   [ { "match": { "message": "payment" } } ] } } }

Dùng filter cho các điều kiện có/không (level, service, khoảng thời gian) và must cho phần full-text cần relevance. Bool query trong script trả về 1 hit cho các log ERROR có nhắc tới payment.

Luyện truy hồi

Trả lời theo trí nhớ. Mỗi câu chỉ một lần chọn.

1. Query nào hợp với field text đã được analyze?

Dùng match cho field text; term không thực hiện analysis.[1]

2. Mệnh đề bool nào bỏ qua việc tính điểm?

filter bỏ qua điểm; must và should có góp điểm.[2]

3. Kiểu field tốt nhất cho user id?

Field chứa giá trị chính xác là field keyword, search bằng term.

4. Những mệnh đề bool nào được cache?

filter và must_not chạy trong filter context và được cache.[2]
